🇱🇰 Sri Lanka Tourism Analytics (2018–2025)

End-to-End Data Analytics Project | Excel • SQL Server • Python • Power BI

An end-to-end data analytics project focused on analyzing Sri Lanka's tourist arrival data from 2018 to 2025. This project demonstrates the complete data analytics workflow, from raw data preparation and database management to Python-based data processing and interactive Power BI dashboard development.

---

📌 Project Overview

Tourism plays an important role in Sri Lanka's economy. This project explores tourist arrival patterns, annual trends, monthly variations, and country-level contributions using historical tourism data.

The objective is to transform raw tourism data into meaningful insights through data cleaning, validation, analysis, and visualization.

🎯 Project Objectives

- Analyze Sri Lanka's tourist arrivals from 2018 to 2025.
- Clean and transform raw tourism datasets.
- Store and manage structured data using SQL Server.
- Perform data processing and validation using Python.
- Identify annual and monthly tourist arrival trends.
- Explore the leading countries contributing to tourist arrivals.
- Develop an interactive Power BI dashboard.

🔄 Project Workflow

1. Data Collection – Gathered annual Sri Lankan tourism datasets (2018–2025).
2. Data Preparation – Cleaned, transformed, and validated the datasets using Excel.
3. SQL Analysis – Imported and managed tourism data in SQL Server and performed data validation.
4. Python Processing – Standardized month names, investigated duplicate records, and prepared the cleaned dataset using Pandas.
5. Power BI Visualization – Built an interactive dashboard to explore tourism trends.
6. Documentation – Organized project files, scripts, reports, and screenshots in GitHub.

📊 Dataset Information

- Period: 2018–2025
- Subject: Sri Lanka Tourist Arrivals
- Final Processed Records: 18,362
- Main Attributes: Country, Month, Arrivals, Year
