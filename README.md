🌍 Project Overview

Sri Lanka Tourism Analytics is an end-to-end data analytics project that explores tourist arrival patterns in Sri Lanka from 2018 to 2025.

This project demonstrates the complete data analytics lifecycle, including data collection, data cleaning, data transformation, SQL database management, Python processing, and interactive Power BI dashboard development.

The main goal is to transform raw tourism data into meaningful insights and understand tourism trends over time.

---

🎯 Project Objectives

- 📌 Analyze Sri Lanka's tourist arrivals from 2018 to 2025.
- 🧹 Clean and transform raw tourism datasets.
- 🗄️ Store and manage structured data using SQL Server.
- 🐍 Perform data processing using Python and Pandas.
- 📈 Identify annual and monthly tourist arrival trends.
- 🌎 Analyze tourist arrivals by country.
- 📊 Develop an interactive Power BI Dashboard.

</p>1️⃣ Data Collection & Preparation – Excel

- Collected annual tourism datasets from 2018 to 2025.
- Removed unnecessary columns and investigated missing values.
- Standardized data formats.
- Prepared structured datasets for further analysis.

2️⃣ Database Management – SQL Server

- Created the SriLankaTourismDB database.
- Imported and organized tourism datasets.
- Performed SQL queries and data validation.
- Created a cleaned master dataset.

3️⃣ Data Processing – Python

Used Python and Pandas to:

- Standardize inconsistent month names.
- Investigate duplicate Country–Month–Year combinations.
- Aggregate repeated records.
- Validate the cleaned dataset.
- Export the processed dataset as CSV.

4️⃣ Data Visualization – Power BI

Developed an interactive dashboard with:

- 📌 Total Tourist Arrivals
- 🌎 Total Countries
- 📅 Years Covered
- 📊 Average Monthly Arrivals
- 📋 Total Records
- 📈 Year-wise Tourist Arrivals
- 📉 Monthly Tourist Arrival Trends
- 🏆 Top 10 Countries
- 🎛️ Interactive Year and Country Slicers
